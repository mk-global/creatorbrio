# CreatorBrio roadmaps

This directory separates **approved or active implementation planning** from **proposed long-range directions**.

| Track | Authority | Status |
|---|---|---|
| [Video Studio](video-studio/README.md) | Implementation program, accepted scope, workstreams, release gates and verified current status | Existing active roadmap |
| [Content automation platform](content-platform/README.md) | One product from idea through research, two human approvals, production and publishing; the Social Automation publisher migration; self-hosted, hosted and mobile direction | **Validated proposal (#216, #218): founder decisions accepted, architecture and sequence proposed; the first milestone's scope was reduced by the founder on 2026-11-23 (FD-K, #248), so it no longer waits on a qualification program** |

The content platform documents **do not amend or supersede** Video Studio requirements, architectural decisions, shipped features or security boundaries; the amendments they need are listed in their RFC and go through their own governed changes.
Do not schedule implementation from them before the decisions are accepted and the milestone's issues are admitted.

Start with the content platform's [README](content-platform/README.md), then its [Architecture RFC](content-platform/ARCHITECTURE-RFC.md), [roadmap](content-platform/ROADMAP.md) and [decision register](content-platform/DECISION-REGISTER.md).

CreatorBrio's existing runtime truth remains the [architecture documentation](../architecture/README.md), [root README](../../README.md), and [maintaining guide](../MAINTAINING.md).

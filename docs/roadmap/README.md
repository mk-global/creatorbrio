# CreatorBrio roadmaps

This directory separates **approved or active implementation planning** from **proposed long-range directions**.

| Track | Authority | Status |
|---|---|---|
| [Video Studio](video-studio/README.md) | Implementation program, accepted scope, workstreams, release gates and verified current status | Existing active roadmap |
| [Future content operations platform](content-platform/README.md) | Exploration of end-to-end research, human approvals, creative production, publishing, self-hosted OSS, future SaaS and mobile | **Proposal only, pending independent architecture review** |

The future-platform proposal **does not amend or supersede** Video Studio requirements, architectural decisions, shipped features or security boundaries. Do not schedule implementation from it before acceptance through separately reviewed decisions and issues.

Start future-platform exploration with its [Architecture RFC](content-platform/ARCHITECTURE-RFC.md), [outcome-based roadmap](content-platform/ROADMAP.md) and [independent review brief](content-platform/ARCHITECTURE-REVIEW.md).

CreatorBrio's existing runtime truth remains the [architecture documentation](../architecture/README.md), [root README](../../README.md), and [maintaining guide](../MAINTAINING.md).

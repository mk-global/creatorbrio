Design system

Quiet, warm and exact. The interface steps back so the work, which is always colourful and always the brand's, is the brightest thing on screen. Every value on this page is read live from the prototype's stylesheet, so this page and the prototype cannot disagree.

Principles

The work is the colour

Surfaces are warm neutrals. Brand colours appear in previews, swatches and art; the interface uses one accent and saves it for the next action.

Say what is true

Every state has words: loading, empty, failed, not connected, early. Times are honest ("a few minutes"). Nothing that does not work looks as if it does.

One of each

One primary action per view, one menu pattern, one dialog pattern, one toast. A person learns each once.

Calm motion

Short, decelerating transitions that confirm cause and effect. No motion is needed to understand anything, and reduced motion removes it.

Colour

Light first. The canvas is a warm off-white so white cards and white slides read as objects on a table rather than holes in the page.

The accent: keep it, split its jobs

CreatorBrio's coral red #e94560 is recognisable and already in the mark. It stays. But as a fill behind white text it measures 3.83:1, and as text on the page 3.67:1; both fail WCAG AA. Two options were rejected: replacing the colour loses the identity, and darkening it everywhere dulls the mark and the focus ring for no gain.

Brand --brand

Identity and indication, where 3:1 is the bar: the mark, the focus ring, the active navigation marker, the selected slide, brand dots.

Accent --accent

The same hue, deeper, for anything read: filled buttons, links, the active chip. White on it measures 5.37:1.

Space, radius and elevation

Spacing

A 4-pixel base: 4, 8, 12, 16, 20, 24, 32, 40, 56. Page gutters are 40 pixels on wide screens, 32 below 1200, 28 below 1024 and 16 on phones.

Elevation

Two levels. Raised lifts cards and secondary buttons off the canvas by a hair. Overlay is for anything above the page: menus, dialogs, toasts and the slide preview. The scrim behind a dialog is warm ink at 44%.

Motion

One curve, cubic-bezier(0.23, 1, 0.32, 1), a strong ease-out the app already defines. Menus pop in over 160 ms, toasts rise over 200 ms, hover colour changes take 140 to 160 ms, and a pressed button scales to 98%. Cards lift by 2 pixels on hover. With reduced motion, durations drop to nothing and nothing moves.

Icons

Lucide, which the app already uses through lucide-react: 1.75 stroke, 16 pixels in small controls, 18 by default, 22 for emphasis. An icon is never the only label of an action except where a tooltip and an accessible name are both present.

Accessibility

  • Contrast: every text and control pair on this page passes WCAG 2.1 AA, measured above.
  • Focus: a 2-pixel brand ring outside a 2-pixel surface gap, visible on any background, shown for keyboard focus only.
  • Keyboard: a skip link; project and template cards are links; menus open on Enter, move with the arrow keys, close on Escape and return focus to their trigger; dialogs trap Tab and return focus when closed.
  • Semantics: navigation landmarks, aria-current on the current page, radio groups for size and format choices, pressed state on filters, live regions for toasts and chat.
  • Targets: buttons and controls are at least 32 pixels in both directions (the phone logo is 28) and phone tab bar items are 48 pixels tall, above WCAG 2.2's 24-pixel minimum. Text links such as "Switch brand" are 21 pixels tall with clear space around them, which the same rule's spacing exception allows.
  • Motion: reduced motion is respected; nothing flashes.
  • Words: no meaning by colour alone; status always has a word, and the Early tag is text.

The Video Studio's stage

Today the Studio is light, like the rest of the app, with a black stage behind the video preview, because video is judged against black. That stays. The --studio-* tokens name that stage and the Studio's illustrations, in the same warm neutrals inverted, so the stage and any later dark Studio surface share one palette. No milestone here restyles the Studio.
